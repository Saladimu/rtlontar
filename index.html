Integrasi Google Sheets

Hubungkan web ini dengan spreadsheet Google Apps Script Anda

Masukkan Web App URL yang telah Anda dapatkan setelah melakukan Deploy as Web App di Google Apps Script.

Panduan Penyiapan Google Sheets & Apps Script:

  1. Buat file Google Sheets baru dan siapkan 4 tab sheet dengan nama exact: Data_Warga, Iuran_Kas, Pengumuman, dan Kegiatan_Warga.
  2. Buka menu Ekstensi > Apps Script pada Google Sheets Anda.
  3. Tempelkan kode Apps Script standar doPost(e) yang menangani pengiriman JSON.
  4. Klik Deploy > New Deployment. Pilih tipe Web app.
  5. Atur Who has access menjadi Anyone (Siapa saja).
  6. Salin Web App URL hasil deployment dan tempelkan pada kolom di atas.
