Demo Mode (Offline) — without Apps Script

For a demo / trial without connecting to Google Sheets, leave publicApiUrl and apiBase empty in config.js. The app then runs in local mode: all data (residents, dues, announcements, activities, requests) is stored only in this browser (localStorage) and is not sent to the server.

  • The public portal does not show local-mode data — it only reads from Google Sheets.
  • After the demo, click Reset Demo Data (Local) to clear the data & display.
  • Data in Google Sheets is never deleted by this button.

Google Sheets & Apps Script Setup Guide:

  1. Create a new Google Sheets file. Tabs & headers are created/fixed automatically on first run: Data_Warga, Iuran_Kas, Pengumuman, Kegiatan_Warga, and Pengajuan_Surat.
  2. Open the Extensions > Apps Script menu in your Google Sheets.
  3. Copy the entire contents of the code.gs file (in this project's Apps Script folder), then paste it to replace the editor's contents.
  4. Click Deploy > New Deployment. Choose type Web app with Execute as: Me.
  5. Set Who has access to Anyone.
  6. In Apps Script open Project Settings > Script Properties, add an ADMIN_TOKEN property with your chosen secret value (e.g. rt-secret-2026). Also add ADMIN_EMAIL to enable email notifications for letter requests (then run the authorizeMail function once).
  7. Copy the Web App URL (ending in /exec) into publicApiUrl in config.js — and into APPS_SCRIPT_URL in Cloudflare Pages if using the /api proxy. Then enter the same value in Admin Token and click Save Token.
  8. Redeploy as New version whenever code.gs changes.
